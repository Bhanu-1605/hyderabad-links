# API specification

OpenAPI is the contract (generated by the API, consumed by `packages/api-client`). Endpoints are added per phase.

| Prefix | Audience | Status |
|---|---|---|
| `/api/v1/public` | anyone | `GET /meta`, `GET /cities`, `GET /cities/{city}/localities`, `GET /categories`, `GET /listings/search?q&city&locality&category&lat&lng&radiusKm&sort&page&pageSize`, `GET /listings/nearby?lat&lng&category&radiusKm&limit`, `GET /listings/{city}/{locality}/{slug}` |
| `/api/v1/auth/owner` | owner login (public) | `POST /otp/request {phone}`, `POST /otp/verify {phone, code}` -> `{accessToken, refreshToken, expiresInSeconds}`, `POST /refresh {refreshToken}`, `POST /logout {refreshToken}` |
| `/api/v1/me` | business owners | `GET /me`; `GET/POST /me/listings`; `GET/PUT /me/listings/{id}`; `POST /me/listings/{id}/submit` (new listings start as `draft`; submit moves them to `pending_review`; an admin approves them in Phase 5) |
| `/api/v1/admin` | administrators | Phase 5 |
| `/api/v1/super-admin` | super-administrators | Phase 7 |
| `/webhooks/razorpay` | Razorpay (signed) | Phase 6 |
| `/health/live` | platform probes | exists |

## `GET /api/v1/public/listings/search`

The directory's one search endpoint. Only `active` listings are ever returned.

| Parameter | Meaning |
|---|---|
| `q` | Business name, service or keyword. Matched against the listing's full-text vector (name weighted above description), against the name by trigram similarity so misspellings still land, and against the category's `search_terms`. Trimmed; cut at 100 characters. |
| `city`, `locality`, `category` | Slugs. A parent category slug also matches its sub-categories. A locality matches listings based there *and* listings that declare it as a service area. |
| `lat`, `lng` | Must be supplied together. Adds `distanceMetres` to every row. |
| `radiusKm` | Only with coordinates. Clamped to 0.1-50. |
| `sort` | `relevance`, `distance` (needs coordinates) or `name`. Defaults to relevance with `q`, distance with coordinates, otherwise name. |
| `page`, `pageSize` | `page` is 1-based; `pageSize` is clamped to 1-50 and defaults to 20. |

Anything unusable answers `400` with a message; out-of-range numbers are clamped rather than refused.

```jsonc
{
  "items": [{
    "slug": "urban-plumbing-services",
    "name": "Urban Plumbing Services",
    "citySlug": "hyderabad", "localitySlug": "beeramguda", "localityName": "Beeramguda",
    "categorySlug": "plumbers", "categoryName": "Plumbers",
    "distanceMetres": 442,          // null unless lat/lng were sent
    "addressLine": "Plot 12", "phonePrimary": "+919876543210", "phoneWhatsapp": null,
    "url": "/hyderabad/beeramguda/plumbers/urban-plumbing-services"
  }],
  "page": 1, "pageSize": 20, "total": 37, "totalPages": 2
}
```

`total` counts every match, not just this page, and is still reported when `page` is past the end
(`items` is then empty) so a client can send the visitor back to page 1.
